# Complete skill badges

These images replace the entire skill symbol, outline, and title on the character sheet.

Use one file per skill: melee (or attack), ranged, magic, defence, thieving, gathering, crafting, cooking. Supported extensions: png, webp, jpg, jpeg, svg. Names are case-insensitive; attack takes priority over melee if both exist.

Missing or failed images fall back to the original icon, outline, and title. Keep transparent margins small and badge proportions consistent. Files are included when the app is rebuilt and deployed, and cached for offline use. Keep each image below 6 MB for offline caching.
